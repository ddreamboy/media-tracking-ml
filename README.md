# Media Tracking ML

Репозиторий машинного обучения для дипломного проекта по мониторингу и анализу медиа-контента. В проекте реализованы пайплайны для тематического моделирования текстов, оценки эволюции тем и автоматического назначения меток с использованием больших языковых моделей (LLM).

## Установка и запуск

Управление зависимостями и виртуальными окружениями осуществляется с помощью пакетного менеджера `pixi`.

Для установки всех зависимостей с поддержкой CUDA (рекомендуется для работы с GPU):
```bash
pixi install -e cuda
```

Для установки зависимостей только для CPU:
```bash
pixi install -e cpu
```

## Структура проекта

- `clearml_pipelines/` - production-пайплайны для ClearML:
  - `hpo/` - скрипты подбора гиперпараметров.
  - `pipelines/` - конвейеры для обучения, валидации и мониторинга моделей.
  - `shared/` - общие утилиты (работа с эмбеддерами, BERTopic, Hugging Face, препроцессингом).
  - `tasks/` - наборы ClearML-задач (загрузка данных, эмбеддинги, фильтрация шума, обучение модели, эволюция тем, сбор метрик).
- `research/` - Jupyter-ноутбуки с исследовательскими экспериментами:
  - EDA и предобработка датасетов.
  - Выбор алгоритмов векторизации и понижения размерности.
  - Построение baseline-модели.
  - Исследование методов отслеживания эволюции тем.
  - Тестирование LLM для разметки.
- `agent/` - настройки окружения для запуска ClearML-агента.

## Основной стек технологий

- Python
- MLOps: ClearML
- Тематическое моделирование: BERTopic
- Эмбеддинги: Sentence Transformers / HuggingFace
- Подбор гиперпараметров: Optuna
- Менеджер пакетов и окружений: pixi
